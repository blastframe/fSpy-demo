fSpy Camera Solver & Workflow

This application runs a faithful mathematical port of the original open-source fSpy solver (`src/gui/solver/solver.ts`, `math-util.ts`, `coordinates-util.ts`). All geometry is computed in fSpy's normalized solver frame and projected using the authoritative $4\times 4$ `cameraTransform` matrix.

  • Vanishing Point Guides: Align the two Red segments with edges parallel to the first world axis, and the two Blue segments with edges parallel to an orthogonal world axis. Hold Shift while dragging for precision movement.
  • 3rd Vanishing Point Mode: When Principal Point is set to From 3rd vanishing point in 2-VP mode, two Purple guide segments appear to compute the orthocenter of the vanishing-point triangle.
  • Reference Distance: Select an axis (X, Y, or Z) or plane to measure along, and drag the ruler markers along the projected world axis to establish real-world metric scale.
  • Native `.fspy` Compatibility: Use Save .fspy to generate a binary `.fspy` project file (`fspy` magic bytes, version 1 header, JSON state + embedded image) compatible with the desktop fSpy app.
